# **App Name**: BizFlow

## Core Features:

- Dashboard Summary: Display a summary of revenue, expenses, and profit in a clear, visual dashboard.
- Appointment Calendar: Display a calendar view for scheduling and viewing appointments.
- Revenue Logging: Form to log income transactions with fields for date, amount, description, and category.
- Expense Logging: Form to log expense transactions with fields for date, amount, description, and category.
- AI-Powered Categorization: Use AI to categorize income and expense entries based on transaction descriptions. The AI model will act as a tool that can suggest categories.

## Style Guidelines:

- Primary color: Teal (#008080) for a professional and calming feel.
- Secondary color: Light gray (#F0F0F0) for backgrounds and neutral elements.
- Accent: Amber (#FFBF00) for highlighting key data points and interactive elements.
- Clean and well-spaced layout for easy navigation.
- Use simple and clear icons to represent different categories of income and expenses.
- Subtle transitions for loading data and navigating between sections.

## Original User Request:
Build a basic ERP for small businesses with a dashboard showing revenue, expenses, and profit, plus a calendar for appointments.
